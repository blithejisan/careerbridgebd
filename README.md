## 📌 About

CareerBridge BD is a full-stack web application designed to connect
fresh graduates of Bangladesh with entry-level job opportunities.
Built as a final project for Software Engineering & Database Systems
at Green University of Bangladesh.

---

## 🛠️ Tech Stack

| Layer      | Technology                    |
|------------|-------------------------------|
| Frontend   | React.js 18, Tailwind CSS     |
| Backend    | Node.js + Express.js          |
| Database   | MySQL 8.0                     |
| Auth       | JWT + bcrypt                  |
| File Upload| Multer (CV PDF upload)        |
| Email      | NodeMailer (SMTP)             |

---

## 👥 User Roles

- **Graduate** — Register, build profile, upload CV, apply for jobs
- **Employer** — Post jobs, manage applicants, shortlist candidates
- **Admin** — Manage users, verify employers, moderate listings
